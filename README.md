# gear-ball

This repo contains code that can simulate the positions and movement of a [Gear Ball](https://www.thecubicle.com/products/mefferts-gear-ball?srsltid=AU7gw4WyZ5dORPP-2_cs6hMFnZERNhoHYeIqRxR_KAz6QuoWGifC26KM), also known as Meffert's Gear Ball.
It also contains code that enables searching for "algorithms" to help solve the ball, by indicating a starting ball-state and a goal ball-state.
